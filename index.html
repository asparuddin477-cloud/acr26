Koneksi Firebase Cloud

Hubungkan aplikasi dengan Cloud Firestore

Cara Mendapatkan Config:
  1. Buka Firebase Console lalu buat project baru.
  2. Buka Firestore Database lalu klik Create Database (Pilih Mode Test).
  3. Masuk ke Project Settings > Add Web App (ikon </>).
  4. Salin objek firebaseConfig lalu tempel di bawah ini.
